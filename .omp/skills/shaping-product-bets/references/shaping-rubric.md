# Shaping Rubric

## Readiness gates

| Gate | Pass condition |
|---|---|
| Problem | Observable pain/opportunity independent of solution. |
| User/moment | Concrete actor and triggering context. |
| Alternative | Current behavior and switching friction known. |
| Evidence | At least one source-backed signal; limits stated. |
| Appetite | Time/cost/risk/reversibility boundaries explicit. |
| Shape | Core mechanism described without premature architecture. |
| Rabbit holes | Critical uncertainty changes boundary or test. |
| No-gos | Adjacent scope explicitly excluded. |
| Success | Observable behavior/outcome and measurement window. |
| Kill | Evidence can stop the bet. |

Any failed gate that can reverse the choice yields `NEEDS_EVIDENCE`. A structurally complete but economically weak bet may yield `REJECT`.

## Serious alternative test

An alternative is serious only when it changes at least one of:

- target user or moment;
- value-delivery mechanism;
- acquisition/distribution path;
- monetization path;
- data/operational burden;
- appetite or reversibility.

Cosmetic variants do not earn table rows.
