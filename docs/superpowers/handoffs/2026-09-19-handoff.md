## Gotchas that have bitten before

- **Native build uses the wrong Rust.** `/opt/homebrew/bin` shadows rustup, so `rustc` is Homebrew stable 1.97.x and ignores `rust-toolchain.toml`'s nightly pin → `portable_simd` errors. Always `export PATH="$HOME/.cargo/bin:$PATH"` first; confirm `rustc --version` says nightly.
- **Stale native addon** → `editDescription is not a function` on any real turn. Rebuild natives for each new upstream base; copying an old `.node` between worktrees breaks edit tooling.
- **gitleaks pre-push hook** blocks pushing large upstream ranges (false positives in upstream commits: tokenizer name `claude-v5-sonnet`, a public GitLab OAuth client ID, a `sk-or-v1-minted` fixture). Route through a PR; don't `--no-verify` without the user.
- **Generated files**: `bun.lock`, `packages/catalog/src/compat/rules.json`, `auth-ids.ts` are regenerated (`bun install`, `bun packages/catalog/scripts/compile-compat.ts`), never hand-merged.
- **Duplicate compat rules** throw `AmbiguousOverlapError` and take down the whole registry. After any merge, run `omp models list` — a passing typecheck does not catch this.
- **Installing the binary**: back up first, then `cp` to `omp.new` and `mv` into place. An in-place `cp` over `~/.bun/bin/omp` gets SIGKILLed by macOS code-signing.
- **Cold model cache** shows only the 6 static claude-code models; a `models refresh` restores 9. That is not a regression. (Separately unresolved on the rebased tree: discovery returns 9 standalone but the registry surfaced 6 across repeated runs.)
- Upstream absorbed `packages/hashline` into `crates/pi-edit` — its absence is expected.
